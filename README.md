# DSA-maze-solver-C-
 

About the Project
This project is a simple maze solving program written in C++. It finds a path from a starting point (S) to an ending point (E) in a gridnbased maze.

The goal of this project was to understand and implement basic data structures and algorithms in a practical way.

How it Works
The maze is represented as a 2D grid where:
- `S` = Start point  
- `E` = End point  
- `0` = Open path  
- `1` = Wall  

The program uses two different approaches:
- Depth First Search (DFS) using a stack
- Breadth First Search (BFS) using a queue

It explores the maze step by step until it finds a valid path to the destination.

Concepts Used
- Stack (for DFS)
- Queue (for BFS)
- Linked List (to store path)
- Basic graph traversal ideas
